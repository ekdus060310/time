# 중간고사 스터디 플래너

HTML · CSS · JavaScript만으로 만든 단일 페이지 스터디 플래너입니다. 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 동작하고, 모든 기록은 브라우저 `localStorage`에 저장됩니다.

## 바로 열기

GitHub Pages로 배포하면 주소창에 **https://ekdus060310.github.io/time/** 을 입력해 바로 열 수 있습니다.
(저장소 Settings → Pages → Source: Deploy from a branch → Branch: `claude/study-planner-spa-qyv47k`, 폴더 `/ (root)` → Save)

## 기능

- **D-Day (우측 상단)**: 10/19 중간고사까지 남은 날과 시간을 1초마다 갱신합니다.
- **오늘의 체크리스트**: 날짜별로 공부할 항목을 과목별로 묶어 보여 줍니다. 체크하면 취소선으로 완료 처리됩니다.
- **미완료 과목 스케줄 재배치**: 하루를 마치고 누르면 그날(오늘 플랜)을 마감합니다.
  1. 완료하지 못한 항목을 다음 날로 이월합니다. 마감한 날에는 ‘다음 날로 이월됨’으로 남습니다.
  2. 다음 날부터 마지막 시험일(10/22)까지 전체 스케줄을 다시 계산해 화면에 그립니다.
  3. 바로 직전의 재배치는 ‘되돌리기’로 취소할 수 있습니다.
- **개인 일정 · 메모**: 날짜별로 개인 일정과 메모를 추가합니다. 시작 시간은 `--:--`(시:분, 24시간)으로, 소요 시간은 분으로 넣습니다. 15:00에 30분을 넣으면 `15:00~15:30`으로 들어가고, 그만큼 그날 공부 가능시간에서 빼서 스케줄을 다시 계산합니다.
- **과목별 진도**: 과목을 펼치면 세부 강의 목록과 배정된 날짜가 보입니다. 이미 들은 강의를 체크하거나 학습 항목(예: 기출 풀이)을 직접 추가할 수 있습니다.
- **전체 스케줄**: 9/28 ~ 10/25 달력에 날짜별 배정 시간과 과목 구성을 보여 줍니다. 칸을 누르면 그날 체크리스트로 이동합니다.
- **설정**: 요일별 가용시간, 과목별 현장수업 요일, 영상강의 공부시간 배율, 누적 복습 주기, 시험 당일 차감 시간을 바꿀 수 있습니다.

## 저장과 기기 간 동기화

- claude.ai에 올린 페이지에서는 로그인한 계정마다 비공개 문서 하나에 전체 기록을 저장하므로, 같은 계정으로 로그인한 어느 기기에서 열어도 같은 체크리스트가 보입니다. 다른 기기에서 저장한 내용은 실시간으로 반영됩니다. 상단의 ‘모든 기기 동기화됨’ 표시로 상태를 확인할 수 있습니다.
- 파일로 직접 열거나 다른 곳에 올리면 그 브라우저의 `localStorage`에만 저장됩니다 (‘이 브라우저에만 저장’).
- 여러 기기에서 거의 동시에 고치면 나중에 저장한 쪽이 이깁니다.

## 기본 데이터

| 요일 | 월 | 화 | 수 | 목 | 금 | 토 | 일 |
|---|---|---|---|---|---|---|---|
| 공부 가능시간 | 9h | 9h | 7h | 8h | 4h | 8h | 7h |

| 시험일 | 과목 |
|---|---|
| 10/19(월) | 이산수학, 리눅스시스템 |
| 10/21(수) | 위성정보 이해와 처리 |
| 10/22(목) | 데이터베이스, 인문학으로 바라본 과학생활 |

- 이산수학: 영상강의 11개 (1장 ~ 6장)
- 리눅스시스템 · 위성정보 · 인문학: 주차별 영상강의 7개 + 현장강의 복습 7회
- 데이터베이스: 영상강의 14개 (CH1-A ~ Normalization_A) + 현장강의 복습 7회
- 융합보안 프리캡스톤은 강의가 없어 계획에서 뺐습니다.
- 현장수업 요일: 월 이산수학·리눅스시스템 / 수 위성정보 / 목 데이터베이스·인문학
- 영상강의 공부시간 = 영상 1.5h × 배율(1.5 ~ 2.5배). 기본값 ‘자동’은 2.5배부터 낮춰 가며, 시험 전날 전까지 모든 강의·복습이 들어가는 가장 큰 배율을 고릅니다. 이미 들은 강의를 체크하면 여유가 생겨 배율이 올라갑니다.
- 현장강의 복습은 1h로 계산합니다.

## 스케줄 계산 규칙 (`app.js`의 `replan`)

하루씩 앞으로 나아가며 다음 순서로 채웁니다. 이미 완료한 항목은 그 날짜에 고정되고 나머지는 모두 다시 배치됩니다.

1. **이월 복습**: 전날 끝내지 못한 훑어보기·누적 복습을 먼저 넣습니다. 미완료 강의는 진도 큐 맨 앞에 남아 있다가 다시 배치됩니다.
2. **누적식 진도**: 전날 공부한 강의를 다음 날 ‘어제 공부한 내용 훑어보기’로 짧게 복습합니다 (항목당 0.25h, 과목당 최대 0.75h).
3. **주기 누적 복습**: 9/28부터 7일마다(10/4, 10/11) 과목별로 지금까지 배운 범위를 누적 복습합니다.
4. **새 진도**: 과목별로 주차 순서를 지키며, 남은 학습량 ÷ 시험 전날까지 가용시간이 큰 과목부터 배치합니다. 같은 날 한 과목에 몰리지 않도록 분산하고, 같은 주차 영상강의를 들은 뒤에 현장강의 복습을 넣습니다. 영상강의는 수업 전날까지 끝내도록 앞당기고(뒤 주차의 마감은 앞 주차에도 적용), 마감이 급한 강의부터 배치합니다. 현장강의 복습은 수업 당일 이후에 넣습니다.
5. **시험 전날 올인**: 시험 전날(10/18, 10/20, 10/21)에는 다음 날 시험 과목만 배치하고, 남은 시간은 총정리로 채웁니다.
6. **남는 시간**: 시험이 가까운 과목부터 문제풀이로 채웁니다.
7. 시험 당일에는 시험 1과목당 1.5h를 가용시간에서 뺍니다.

시험 전까지 배정하지 못한 항목이 생기면 화면 상단에 경고가 뜹니다.
